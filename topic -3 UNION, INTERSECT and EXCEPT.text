2. UNION
Definition: UNION combines the results of two or more SELECT statements and removes duplicate rows.

SELECT column_name FROM table1
UNION
SELECT column_name FROM table2;


SELECT Student_ID, Name
FROM Java_Students

UNION

SELECT Student_ID, Name
FROM Python_Students;

Result:
Student_ID	Name
        1	Arun
        2	Binu
        3	Chris
        4	David


UNION ALL – useful distinction
UNION ALL also combines results, but it does not remove duplicates.
SELECT Student_ID, Name
FROM Java_Students



UNION ALL  ----> speical varient of uion   heading

SELECT Student_ID, Name

The result contains six rows because Binu and Chris appear twice.

UNION ALL is useful when duplicate rows must be retained. It is a supporting distinction to know alongside UNION.





3. INTERSECT  -----> heading
Definition: INTERSECT returns only the rows that are common to both query results.

Syntax:
SELECT column_name FROM table1
INTERSECT
SELECT column_name FROM table2;


Example:
SELECT Student_ID, Name
FROM Java_Students

INTERSECT

SELECT Student_ID, Name
FROM Python_Students;


Result:
Student_ID	Name
2	Binu
3	Chris

What happened?
- Arun is only in Java, so he is excluded.
- David is only in Python, so he is excluded.
- Binu and Chris are in both, so they are returned.
Remember
 INTERSECT = only common rows.

 Important: The order matters. If you reverse the two queries, the result will be David instead of Arun.


 8. Exam-ready answer (5 marks)
Question: Explain UNION, INTERSECT and EXCEPT operations in SQL.

SQL provides set operations to combine and compare the results of multiple SELECT statements.
1. UNION: Combines the results of two or more queries and eliminates duplicate rows.
2. INTERSECT: Returns only the rows that are common to the results of both queries.
3. EXCEPT: Returns rows from the first query that are not present in the second query.
The queries used in set operations must return the same number of columns, with compatible data types in corresponding positions.

These operations help retrieve combined, common and differing records from database query results.
