Topic 2 – Basic Queries in SQL

1. What is an SQL query?
An SQL query is an instruction given to a database to retrieve or manipulate information.

For example, suppose a college has a table named Student.

2. SELECT statement  - heading

it is used to retrive the data from the database

SELECT column_name
FROM table_name;

to retrie multiple columns  -----> heading

FROM Student;


Selecting all columns  --- heading

SELECT *
FROM Student;





3. WHERE clause  --> heading
The WHERE clause is used to filter records based on a specified condition.

SELECT column_name
FROM table_name
WHERE condition;



SELECT *
FROM Student
WHERE Department = 'CS';


Output:
Student_ID	Name	Department	Age	Marks
101     	Rahul	    CS	    22	85
103     	John	    CS	    21	75


Common comparison operators
Operator	Meaning

Find students whose marks are greater than 80.
SELECT *
FROM Student
WHERE Marks > 80;

SELECT *
FROM Student
WHERE Age = 22;


4. AND, OR and NOT operators
These operators are used to combine or reverse conditions.

AND: Both conditions must be true.
SELECT *
FROM Student
WHERE Department = 'CS'
AND Marks > 80;


OR: At least one condition must be true.

SELECT *
FROM Student
WHERE Department = 'CS'
OR Department = 'Maths';


NOT: Reverses a condition.

SELECT *
FROM Student
WHERE NOT Department = 'CS';



5. DISTINCT keyword
The DISTINCT keyword is used to eliminate duplicate values from query results.

SELECT DISTINCT Department
FROM Student;

Output:
Department
CS
Maths
Commerce

Without DISTINCT, CS and Maths would each appear twice.

Exam definition: DISTINCT is a keyword used with SELECT to return only unique records by eliminating duplicate rows from the result.


6. ORDER BY clause
The ORDER BY clause is used to arrange query results in ascending or descending order.
- ASC – Ascending order (default).
- DESC – Descending order.

SELECT *
FROM Student
ORDER BY Marks ASC;

Name	Marks
David	65
John	75
Rahul	85
Maria	88
Anu     90

SELECT *
FROM Student
ORDER BY Marks DESC;



7. LIMIT clause
LIMIT restricts the number of rows returned by a query. This is commonly used in MySQL.

Example: Retrieve the first three student records.
SELECT *
FROM Student
LIMIT 3;

8. Complete query structure
You can combine these clauses in a single query.
SELECT Name, Marks
FROM Student
WHERE Marks > 70
ORDER BY Marks DESC
LIMIT 3;


Understand the execution:
1. FROM – Selects the Student table.
2. WHERE – Filters students with marks greater than 70.
3. SELECT – Returns Name and Marks.
4. ORDER BY – Arranges the results from highest to lowest marks.
5. LIMIT – Returns only the first three rows.
Important SQL query order

This is a simplified logical explanation, not the actual internal execution order of every SQL engine.


Exam-ready notes
Question: Explain the basic SQL query structure.

SQL queries are used to retrieve and manipulate data stored in relational database tables. The SELECT statement is used to retrieve data, while the FROM clause specifies the source table. The WHERE clause filters records based on conditions. DISTINCT eliminates duplicate values, and ORDER BY arranges the query results in ascending or descending order. The LIMIT clause restricts the number of returned rows in MySQL.

The general syntax is:
SELECT column_name
FROM table_name
WHERE condition
ORDER BY column_name ASC;
