1. What is SQL?  ---> heading
SQL stands for Structured Query Language.

SQL is a standard language used to communicate with relational database management systems (RDBMS).

It allows users to:
- Create databases and tables.
- Insert records into tables.
- Retrieve stored information.
- Update existing records.
- Delete records.
- Control access to database information.

2. Characteristics of SQL  ---> heading

The important characteristics are:
1. Simple language: SQL uses understandable commands.
2. Declarative language: Users specify what data they need rather than describing every step to retrieve it.
3. Standardised language: SQL has standards that support different relational database systems.
4. Data manipulation: It supports inserting, updating, deleting and retrieving records.
5. Data definition: It allows users to create and modify database structures.
6. Integrity and security: It supports constraints and access control.




3. Categories of SQL Commands   ----> heading
SQL commands are commonly classified into five categories.
SQL command classification
DDL – Data Definition Language

Used to define and modify database structures.

Commands: CREATE, ALTER, DROP, TRUNCATE.

DML – Data Manipulation Language

Used to modify data stored in tables.

Commands: INSERT, UPDATE, DELETE.

DQL – Data Query Language

Used to retrieve data.

Command: SELECT.

DCL – Data Control Language

Used to control database access and permissions.

Commands: GRANT, REVOKE.

TCL – Transaction Control Language

Used to manage database transactions.

Commands: COMMIT, ROLLBACK, SAVEPOINT.





4. Difference between SQL and MySQL
This is a useful supporting distinction.
SQL	MySQL
SQL is a query language.	MySQL is a relational database management system.
Used to communicate with databases.	Used to store and manage databases.
It is a language.	It is database software.

For example, SELECT * FROM Student; is SQL, while MySQL is one system that can execute that query.


5. Advantages of SQL
- Easy to learn and use.
- Efficient data retrieval.
- Supports large amounts of structured data.
- Provides data security and integrity features.
- Supports multiple users.
- Allows database structure and data manipulation.




Exam-ready answer: Overview of SQL (5 marks)
Question: Explain SQL and its characteristics.

Answer:

SQL (Structured Query Language) is a standard language used to communicate with relational database management systems. It is used to create, retrieve, insert, update and delete data stored in relational databases.

The important characteristics of SQL are:
1. SQL is a simple and user-friendly language.
2. It is a declarative language that specifies what data is required.
3. It supports database creation and modification.
4. It provides commands for inserting, updating, deleting and retrieving data.
5. It supports data integrity and security.
6. It is widely used in relational database management systems.
SQL commands are classified into DDL, DML, DQL, DCL and TCL.

Thus, SQL provides an effective way to manage and manipulate relational databases.
